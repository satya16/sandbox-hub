sandbox-hub API tester

Minimal, ephemeral -- nothing here is saved. Send a request, or poll one on an interval.

This runs in its own container. To reach another sandbox-hub instance, use its Internal URL (shown on its card, e.g. http://sandboxhub-rest-api-abc123:8000/items) -- not its localhost:PORT URL, which only your own machine can reach.
